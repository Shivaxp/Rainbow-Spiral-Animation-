🌈 Rainbow Spiral Animation using OpenCV
🌀 Project Overview
This project creates a rotating rainbow spiral animation using Python and OpenCV.
Each point in the spiral changes color smoothly through the rainbow spectrum, creating a mesmerizing visual that blends mathematics, programming, and art.

The animation is built from simple trigonometric functions and color transitions based on sine waves — showing how math and creativity can combine to produce stunning motion graphics.

🎨 Features
Dynamic, continuously rotating spiral animation
Smooth rainbow color transitions using sine waves
Adjustable size and speed
Real-time rendering using OpenCV
Minimal code with beautiful visual output

🧠 Concepts Used
Trigonometric functions (sin, cos) for spiral generation
Sine wave color modulation for rainbow transitions
OpenCV graphics drawing (cv2.circle, cv2.imshow)

Frame-by-frame animation control with Python loops and timing
